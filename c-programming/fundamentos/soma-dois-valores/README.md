<h1 align="center">Soma de Dois Valores</h1>

<p align="center">
  Programa desenvolvido em C para realizar a soma de dois valores.
</p>

## 📌 Sobre o projeto

Este projeto foi desenvolvido para praticar **fundamentos da linguagem C**, utilizando variáveis, atribuição de valores e operações matemáticas.

O programa define dois valores diretamente no código e realiza a soma entre eles.

## 🧮 Operação realizada

```text
Soma = Valor 1 + Valor 2
```

## 🧠 Conceitos praticados

- Declaração de variáveis
- Tipo `int`
- Atribuição de valores
- Operação de adição
- Saída de dados com `printf`
- Função `main`

## 💻 Exemplo

```text
Valor 1 = 20
Valor 2 = 20

Resultado da soma: 40
```

## ▶️ Como executar

Compile o programa:

```bash
gcc soma_dois_valores.c -o soma_dois_valores
```

Execute:

```bash
./soma_dois_valores
```
