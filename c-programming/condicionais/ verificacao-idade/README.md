<h1 align="center">Verificação de Idade</h1>

<p align="center">
  Programa desenvolvido em C para verificar se uma pessoa é maior ou menor de idade.
</p>

## 📌 Sobre o projeto

Este projeto foi desenvolvido para praticar **estruturas condicionais em C**.

O programa possui uma idade definida diretamente no código e verifica, através de uma condição, se a pessoa é **maior ou menor de idade**.

## 🧠 Conceitos praticados

- Declaração de variáveis
- Tipo `int`
- Atribuição de valores
- Estrutura `if`
- Estrutura `else`
- Operadores relacionais
- Saída de dados com `printf`
- Função `main`

## 🔍 Regra utilizada

```text
Idade >= 18 → Maior de idade
Idade < 18  → Menor de idade
```

## 💻 Exemplo

```text
Idade = 18

Maior de idade
```

## ▶️ Como executar

Compile o programa:

```bash
gcc verificacao_idade.c -o verificacao_idade
```

Execute:

```bash
./verificacao_idade
```
